# Deploying FieldBook to Render

FieldBook ships with a Render Blueprint (`render.yaml`) that provisions the web
service **and** a managed Postgres database together. Free tier works for a demo.

## One-time setup (~5 minutes)

1. Push this branch to GitHub (already done if you're reading this on GitHub).
2. Go to <https://dashboard.render.com> and sign in (GitHub login is easiest).
3. Click **New +** → **Blueprint**.
4. Connect this repository and, when prompted for a branch, pick
   **`claude/service-booking-saas-mvp-1jftfq`** (or `main` once this PR is merged).
5. Render reads `render.yaml`, shows a `fieldbook` web service + a
   `fieldbook-db` Postgres. Click **Apply**.
6. Wait for the first build (~2–4 min). When it's live you'll get a URL like
   `https://fieldbook-xxxx.onrender.com` — **that's your shareable link.**

## After the first deploy

- Open the URL, click **Start free trial**, and create your business — the app
  auto-creates its database tables on first boot.
- Your public booking page is `https://<your-url>/book/<your-slug>`.
- **Set `APP_URL`** (Render dashboard → the service → Environment) to your live
  URL so links inside reminder emails/texts point to the right place, then
  redeploy. Everything else is wired automatically:
  - `DATABASE_URL` — injected from the managed database
  - `JWT_SECRET` — generated by Render
  - `NODE_ENV=production` — enables Postgres SSL automatically

## Turning on SMS + email (optional)

The app runs fine without these — messages are skipped and logged. To send for
real, add these env vars in the Render dashboard and redeploy:

| Variable | From |
|---|---|
| `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_FROM_NUMBER` | twilio.com console |
| `SENDGRID_API_KEY`, `SENDGRID_FROM_EMAIL` | sendgrid.com (verified sender) |

## Notes

- The free Postgres instance expires after 90 days; upgrade the database plan
  in `render.yaml` (`plan: free` → `starter`) for anything beyond a demo.
- The free web service sleeps after inactivity and takes a few seconds to wake
  on the first request — normal for the free tier.
- `DATABASE_SSL` can force SSL on/off explicitly if you point at a different
  Postgres host; otherwise it follows `NODE_ENV`.
